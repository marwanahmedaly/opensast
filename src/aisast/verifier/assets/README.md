# Bundled guided prompt assets

These unmodified files come from the already evaluated VulnHunterX checkout:
`config/prompts/python_questions.yaml` and `config/rule_categories.yaml`.
Their original copyright/SPDX notices and GNU LGPL 2.1 license are retained.
`provenance.json` records the source repository, archived local revision and hashes.

That local research revision cannot be fetched from the public upstream, so
product scanning loads these package files instead of requiring the submodule.
Their contents and the existing four-CWE guided question rendering are unchanged.
